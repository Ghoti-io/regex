# Patterns of the kind that appear in JSON Schemas, configuration files and
# validation code. Collected for documentation/work-packages.md WP-14, which
# sets grx_limits_default() from what real patterns cost rather than from a
# guess.
#
# One per line: the flags, a tab, then the pattern. A line beginning with `#`
# is a comment and a blank line is ignored.
#
# The point of this file is the *upper* end of the distribution. A default
# that every pattern here clears with room to spare is a default no honest
# schema will meet; one that any of them exceeds is a default that would
# reject working software.
