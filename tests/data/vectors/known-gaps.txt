# The vectors this library does not answer the way its oracle does.
#
# One line per record: dialect, flags, pattern, subject, and why.
# Tab-separated; the pattern and the subject are escaped the way the runner
# escapes them, so that a tab or a newline inside one cannot split the line.
#
# This file is a gate in both directions. A vector that fails and is not
# listed here fails the suite; a vector that is listed here and *passes* fails
# it too, with "remove the entry" - so the list can only shrink by somebody
# noticing, and never grows by accident.
#
# The rates the README publishes are the rates without these: a known gap is
# counted and named, never counted as a pass.
#
# Regenerating: run testVectors, which prints the line to add beneath every
# failure it does not recognise. The *reason* is written by hand. A reason
# that begins "not yet classified" is one nobody has looked at, and is meant
# to be read as the admission it is.

perl		X(?!b+(?!(c+)*(?!(c+)*d))).*X	aXbbbbbbbcccccccccccccaaaX	the capture state a *repeat* inside a negative lookahead leaves behind. Which captures survive a negative lookaround at all is settled - documentation/dialects.md section 5.17, probed three ways: Perl keeps what the body wrote before failing, pcre2test and Node discard it, and this library follows the dialect. What is not settled is what the last write *was* when the body's failing part is a loop. Perl reports group 2 of `(?!(aa){2}$)` against "aaa" as 0-2 and group 1 of `(?!(aa)*$)` against the same subject as unset, so the counted form keeps its last successful iteration and the starred form does not - which is a fact about where Perl's own engine restores an offset, not a rule a second engine can follow. Reproducing it means reproducing regexec.c

perl		^(.\\1?)(?1)$	aba	a backreference to the group it is written inside. Perl reads what the *previous* iteration captured: in `^(a\1?){4}$` against "aaaaaa" the second iteration's `\1` is the "a" the first one took, and this library reads the half-written span instead - the start slot already moved to this iteration, the end slot has not.
