# The vectors this library does not answer the way its oracle does.
#
# One line per record: dialect, flags, pattern, subject, and why.
# Tab-separated; the pattern and the subject are escaped the way the runner
# escapes them, so that a tab or a newline inside one cannot split the line.
#
# This file is a gate in both directions. A vector that fails and is not
# listed here fails the suite; a vector that is listed here and *passes* fails
# it too, with "remove the entry" - so the list can only shrink by somebody
# noticing, and never grows by accident.
#
# The rates the README publishes are the rates without these: a known gap is
# counted and named, never counted as a pass.
#
# Regenerating: run testVectors, which prints the line to add beneath every
# failure it does not recognise. The *reason* is written by hand. A reason
# that begins "not yet classified" is one nobody has looked at, and is meant
# to be read as the admission it is.
