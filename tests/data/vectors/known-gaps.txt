# This file is a gate in both directions. A vector that fails and is not
# listed here fails the suite; a vector that is listed here and *passes* fails
# it too, with "remove the entry" - so the list can only shrink by somebody

# counted and named, never counted as a pass.

# that begins "not yet classified" is one nobody has looked at, and is meant
# to be read as the admission it is.
